# Лабораторная работа № 7 — адаптивная вёрстка

Ветка: `lesson7`. Страница сверстана по макетам Figma на 1440, 768 и 425 px.

Завершены разделы отраслей, проекта I-teka, обсуждения проекта, этапов разработки,
команды, книги и FAQ. Оригинальные изображения и иконки сохранены локально.
Сохранены анимация первого экрана, мобильное меню и страница контактов.

## Запуск

```sh
npm ci
npm start
```

Страница: http://localhost:8080/src/index.html. Остановка сервера — Ctrl+C.
`npm run dev` включает пересборку SCSS, `npm run build` собирает CSS отдельно.
Можно также открыть корневой `index.html` непосредственно в браузере.

## Адаптив

- От 1280 px — настольная компоновка, три колонки отраслей, две колонки FAQ.
- 768–1279 px — планшетная компоновка, две колонки отраслей, этапы и FAQ в одну колонку.
- До 767 px — мобильная компоновка, формы в одну колонку, изображения над описаниями.
- До 374 px дополнительно уменьшены отступы для узких телефонов.

Основные стили новых разделов: `src/assets/styles/_sections.scss`.
Точка входа: `src/assets/styles/style.scss`. Собранный `style.css` включён в проект.

Меню работает через якорь и `:target`, FAQ — через `details` и `summary`.
Формы проверяют обязательные поля средствами браузера и выводят подтверждение;
данные никуда не отправляются. Отдельная ссылка скачивает учебную памятку.
В списке проектов выбран I-teka. Остальные кнопки недоступны, поскольку материалы
для этих кейсов не предоставлены. Нажатия не прокручивают страницу к форме заявки.
